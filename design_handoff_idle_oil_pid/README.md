# Idle Oil — Дизайн-хэндофф

P&ID-схема в стиле инженерного чертежа для idle-игры про добычу нефти. Десктоп + мобильный.

## Что это

HTML-прототипы — **референсы дизайна**, не код для копирования. Реализуй в своём стеке (React/Vue/нативное), используя существующие компоненты и паттерны.

Откройте `Idle Oil Designs.html` — оба макета лежат в DesignCanvas рядом. Канвас и Tweaks-панель — служебные, в продакшен не идут.

## Дизайн-токены (в `tokens.css`)

**Цвета**
- `--blue-0: #0E2A3A` — фон чертежа
- `--blue-line: #6EC3E6` — циан, линии и текст
- `--amber-deep: #F4B454` — нефть, акценты, активные состояния
- `--ok-green: #79D399` — статус «работает»
- `--rust: #9C9485` — статус «выкл»

**Шрифты**
- UI — Inter
- Display — Space Grotesk (заголовки)
- Mono — JetBrains Mono (метки, цифры, коды)

**Стиль**
- Углы только прямые (без border-radius)
- Тонкие 0.5–1.5px обводки в стиле чертежа
- 24px фоновая сетка через repeating-linear-gradient

## Десктоп (1280×820)

Колонки: **схема поля** + правый сайдбар R&D (440px). Сверху top-bar (56px) со статами, снизу bottom-bar (160px) с тремя панелями.

**Схема (SVG 880×632)**
- 3 эллиптических контура пласта (амбер, dashed)
- 5 станций (P&ID-символ: круг + крестовина + мини-pumpjack), у каждой бирка `PIT-001 / W-01`, дуга заполнения, статус-точка, ставка добычи
- Узел сбора M-01 в центре, резервуар справа
- Трубы: тройной stroke (cyan + blue-0 + анимированный амбер `flow-line`)
- Пунктирный «СЛОТ 6» — место под будущую станцию

**Bottom-bar**
- ЭНЕРГОКОНТРАКТ — таймер + сегментный прогресс + продлить/расширить МВт
- БИРЖА — крупная цифра + кнопки 10/50/Всё
- СТАНЦИИ — 6-колоночная сетка (5 + locked R6)

**Сайдбар R&D** — дерево из 8 нод (готовые / доступные / заблокированные), линии-связи между уровнями.

**Инспектор станции** — открывается при клике на станции или слоте, плавающая панель слева-снизу. Действия: ВКЛ/ВЫКЛ, ПРОДАТЬ (только при запасе <15%).

## Мобильный (390×844)

Сверху вниз:
1. **Статус-бар** (44px) — название поля, $, нефть, XP, МВт
2. **Энергия-баннер** (38px) — таймер контракта, прогресс, кнопка `+$140`
3. **Схема** (420px) — вертикальный layout: резервуар сверху, узел сбора в центре, 5 станций вокруг + СЛОТ 6
4. **Биржа-плашка** — счёт нефти + `10% / 50% / ВСЁ`
5. **Контент-таб**: СТАНЦИИ (список карточек) или R&D (вертикальный список нод)
6. **Tab-bar** (2 вкладки)

**Bottom-sheet инспектор** — выезжает снизу при тапе по станции (на схеме или в списке). Затемнение, drag-handle, действия ВКЛ/ВЫКЛ + ПРОДАТЬ.

## Ключевые анимации

- **Поток нефти** в трубах: `stroke-dasharray: 4 4`, animate `stroke-dashoffset 0 → -16` за 1.6s linear infinite (период должен быть кратен паттерну, иначе дёргается)
- **Pumpjack walking beam**: rotate `-12° ↔ +18°` over 2.6s
- **Полированный шток**: `scaleY(0.55 ↔ 1.0)` с `transform-origin: bottom`. **Не вкладывать в группу beam** — иначе шток оторвётся от устья
- **Marching ants** на доступных R&D-нодах и selection-кольце станции

## Реализация (что важно)

- Состояние: `selected: number | null`, `stationsData: Station[]` — источник правды для карты и списка
- Действия: ВКЛ/ВЫКЛ, продать станцию, купить слот, продлить контракт, продать нефть %
- Тик-цикл: декремент таймера, истощение пласта, накопление нефти/денег, всплывающие `+X` бабблы
- Локализация: только русский в макете; вся копия в JSX-литералах
- На SVG `<rect>` нельзя CSS `background-image` — используй `<pattern>` (см. tank-oil-hatch)
- Строй ряды кнопок через `display: flex; gap: ...`, не inline-spacing
- Все размеры/цвета/спейсинги бери из макета пиксель-в-пиксель

## Внешние зависимости

Только Google Fonts (Inter / Space Grotesk / JetBrains Mono). Никаких иконок и картинок — всё SVG/CSS.
